# 📓 eNotes

eNotes is a simple and elegant **online note-saving platform** where users can easily create, manage, and store their notes securely. Built with a modern full-stack architecture to deliver a fast, responsive, and reliable experience.

![Logo](https://raw.githubusercontent.com/Vaibhav-Borkar/enotes-frontend/refs/heads/dev/src/assets/enotes_logo.png)

---

## ✍️ Features

- Create and edit notes effortlessly
- Secure and persistent data storage
- Clean and responsive UI (mobile-friendly)
- Fast performance with seamless API integration
- Built with scalable and maintainable code architecture

## 📦 Installation & Run Locally

### 🔧 Backend

```bash
# Clone the backend repo (if separate)
git clone https://github.com/Vaibhav-Borkar/enotes-backend.git
cd enotes-backend
./mvnw spring-boot:run
```

### 🌐 Frontend

```bash
# Clone the frontend repo
git clone https://github.com/Vaibhav-Borkar/enotes-frontend.git
cd enotes-frontend

# Install Yarn (if not already installed)
npm install -g yarn

# Install dependencies
yarn install

# Run the frontend
yarn dev
```
